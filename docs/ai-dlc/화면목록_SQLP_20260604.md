## 1. 메뉴 구조 (계층 트리)

```
SQLP 시험 준비 사이트
│
├─ [홈]
│   └─ SCR-001  대시보드 홈  /
│
├─ [이론 학습]  GNB
│   ├─ SCR-002  이론 목차  /theory
│   └─ SCR-003  이론 본문  /theory/[chapterId]  ← 12챕터 SSG
│
├─ [문제풀이]  GNB
│   ├─ SCR-004  문제풀이 메뉴  /quiz
│   ├─ SCR-005  단원별 문제풀이  /quiz/chapter/[chapterId]
│   ├─ SCR-006  전체 모의고사  /quiz/exam
│   ├─ SCR-007  모의고사 결과  /quiz/result
│   ├─ SCR-008  오답 재풀이  /quiz/wrong
│   └─ SCR-009  북마크 문제풀이  /quiz/bookmarks
│
└─ [실기 연습]  GNB  ★신규
    ├─ SCR-010  실기 문제 목록  /quiz/practical
    └─ SCR-011  실기 상세 풀이  /practical/[practiceId]
```

## 3. 역할별 접근 화면 매핑

> 본 서비스는 로그인·회원가입 없는 **단일 액터(학습자)** 구조. 모든 화면은 인증 없이 접근 가능.

| 액터/역할 | 접근 가능 SCR 목록 | 비고 |
|:---|:---|:---|
| 학습자 (비회원) | SCR-001 ~ SCR-011 전체 | 로그인 불필요. localStorage 기반 진도 저장 |

## 5. 화면별 구성 요소 요약

### SCR-001 대시보드 홈 `/`

| 구성 요소 | 설명 |
|:---|:---|
| HeroBanner | 오늘의 퀘스트·마스코트 표시 |
| ProgressChart | 3과목 정답률 막대 차트 |
| LearningPath | 12챕터 버블 경로 (완료/진행/미시작 색상 구분) |
| WeakChapters | 정답률 하위 챕터 카드 |
| WeeklyXP | 주간 XP 막대 차트 (UI-only) |

### SCR-003 이론 본문 `/theory/[chapterId]`

| 구성 요소 | 설명 |
|:---|:---|
| TheoryTOC (좌) | ## 헤딩 기반 자동 목차 + 스크롤 스파이 |
| TheoryContent (중) | react-markdown + rehype-highlight 렌더링 |
| RelatedQuestions (우) | 챕터 관련 문제 2~3개 미리보기 |

### SCR-006 전체 모의고사 `/quiz/exam`

| 구성 요소 | 설명 |
|:---|:---|
| ExamTimer | 180분 카운트다운, 잔여 20분 경고 |
| QuizNavigator | 70문항 번호 그리드 (3과목 섹션 구분) |
| QuestionCard | 문제·보기 표시 |

### SCR-011 실기 상세 풀이 `/practical/[practiceId]` ★신규

| 구성 요소 | 설명 |
|:---|:---|
| ScenarioPanel | 지문 마크다운 렌더링 (좌측) |
| AnswerTextEditor | SQL 작성 텍스트에어리어, 모노스페이스 폰트 (우측) |
| SampleAnswerToggle | 제출 후 모범 답안 공개/숨김 |
| ScoringGuide | 자기채점 버튼 (0점 / 7점 / 15점) |
