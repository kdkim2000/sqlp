## 이슈 상세

### A11Y-001: AnswerTextEditor label-for 미연결

**현재**:
```tsx
<label className="...">SQL 답안 작성</label>
<textarea ... />
```

**수정**:
```tsx
<label htmlFor="practical-answer" className="...">SQL 답안 작성</label>
<textarea id="practical-answer" ... />
```

---

### A11Y-002: ScoringGuide aria-pressed 누락

스크린리더 사용자가 채점 버튼의 선택 상태를 알 수 없음.

**수정**:
```tsx
<button
  aria-pressed={isSelected}
  aria-disabled={disabled}
  ...
>
```
