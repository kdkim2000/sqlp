## 1. 사업개요

### 1) 사업목적

SQLP(SQL 전문가) 자격증 취득을 목표로 하는 학습자가 3과목 이론 학습, 객관식 문제 반복 풀이, 실기 SQL 작성 연습을 한 곳에서 수행할 수 있는 웹 사이트를 구축한다. 별도 서버·로그인 없이 브라우저의 localStorage만으로 학습 진도를 관리하여, 즉시 사용 가능한 경량 학습 환경을 제공한다.

### 2) 사업개요

기존 SQLD(SQL Developer) 시험 준비 사이트(2과목, 50문항, 90분)를 SQLP 기준으로 전면 개편한다. 주요 변경 내용은 다음과 같다.

| 항목 | 기존 (SQLD) | 신규 (SQLP) |
|:---|:---:|:---:|
| 과목 수 | 2과목 | 3과목 |
| 객관식 문항 | 50문항 | 70문항 |
| 실기 문항 | 없음 | 2문항 (30점) |
| 시험 시간 | 90분 | 180분 |
| 챕터 수 | 5챕터 | 12챕터 |
| 합격 기준 | 60점 이상 + 과목별 40% | 동일 |

### 3) 추진 배경

SQLD 자격 취득 후 상위 자격인 SQLP 도전을 위해 기존 사이트를 개편한다. SQLP는 SQL 고급활용 및 튜닝(3과목) 과목이 추가되고, 실기 문항(SQL 튜닝 작성·성능 트러블슈팅)이 포함되어 별도 학습 지원 도구가 필요하다. SQLD 사이트에서 검증된 SSG + localStorage 아키텍처를 그대로 유지하면서 콘텐츠와 기능만 확장한다.

### 4) 사업 내용

- **1과목 (데이터 모델링의 이해)**: 기존 2챕터 유지, 이론 MD + 문제 JSON 35문항
- **2과목 (SQL 기본 및 활용)**: 기존 3챕터 유지, 이론 MD + 문제 JSON 65문항
- **3과목 (SQL 고급활용 및 튜닝)**: 신규 7챕터 추가, 이론 MD + 문제 JSON 120문항
- **실기 연습**: SQL 튜닝 3유형 + 성능 트러블슈팅 2유형 문제, 자기채점 (0/7/15점)
- **모의고사 확장**: 50문항 90분 → 70문항 180분 (3과목 비율: 10+20+40)
- **대시보드 확장**: 2과목 진도율 → 3과목 진도율, 챕터 버블 5→12개
