## 이슈 상세

### #1 — CJ-001 (높음): webpack `require()` 빌드 실패 위험

**문제**: `lib/questions.ts` 20~26줄의 try-catch 패턴은 런타임 기준이지만, webpack은 **빌드 타임**에 `require()` 경로를 정적 분석하여 번들링함. `data/questions/part3_ch1.json` 파일이 없으면 `next build` 시 모듈 해석 오류 발생.

```typescript
// 현재 (빌드 실패 위험)
try { part3ch1 = require('@/data/questions/part3_ch1.json') as Question[] } catch { }

// 해결책 1: 빈 JSON 파일 미리 생성 (권장)
// data/questions/part3_ch1.json 파일 생성 → 내용: []
// → 기존 코드 유지, 빌드 성공

// 해결책 2: next.config.js에서 webpack 모듈 alias 설정
// → 파일 없는 경우 empty-module로 resolve
```

**즉시 조치**: `data/questions/part3_ch1.json` ~ `part3_ch7.json` 7개 파일을 `[]` 내용으로 생성.

### #2 — DRY-001 (중간): 합격 판정 로직 중복

**문제**: `pages/quiz/exam.tsx:183` 에 합격 판정 조건이 하드코딩됨. `lib/progress.ts`의 `isExamPassed()` 함수와 동일 로직.

```typescript
// 현재 (중복)
const passed = examResult.score >= 60
  && examResult.part1Score >= 4
  && examResult.part2Score >= 8
  && examResult.part3Score >= 16

// 수정 (단일 소스)
import { isExamPassed } from '@/lib/progress'
const passed = isExamPassed(examResult)
```

### #3 — SEM-001 (중간): QuizNavigator answer 의미 오류

**문제**: 선택한 옵션(selectedOptions[i] > 0)을 `'skipped'`로 매핑. "선택했음"과 "건너뜀"이 혼용됨.

```typescript
// 현재 (의미 반전)
answers={selectedOptions.map((s) => s > 0 ? ('skipped' as AnswerResult) : null)}
// s > 0 → 선택된 문항인데 'skipped'?

// 의도: "선택 여부" 표시 (색상 구분용)
// 수정안: QuizNavigator에 isAnswered[] prop을 별도로 받거나 주석 명확화
answers={selectedOptions.map((s) => s > 0 ? ('correct' as AnswerResult) : null)}
// 또는 (임시 구분용 표시임을 주석으로)
```

### #4 — TC-002 (중간): localStorage 마이그레이션 미처리

**문제**: 구 `sqld_progress` 키 데이터가 브라우저에 남아있는 경우, 새 키 `sqlp_progress`로 읽으면 기본값 반환 → 진도 초기화됨. 반대로 직접 `sqlp_progress`를 작성한 경우 `part3Score` 필드 누락 시 `undefined` 접근 가능.

```typescript
// loadProgress() 내 방어 코드 추가
const parsed = JSON.parse(raw) as ProgressStore
return {
  ...defaultProgress(),
  ...parsed,
  // part3Score 기본값 보장
  examHistory: (parsed.examHistory ?? []).map((r) => ({
    ...r,
    part3Score: r.part3Score ?? 0,
  })),
}
```
