## v1.0 — SQLD 시험 준비 사이트 (완료 · 2026-05-05)

### 개요

SQLD(SQL Developer) 자격증 시험 준비 사이트를 처음부터 구축.

| 항목 | 값 |
|------|-----|
| 개발 기간 | ~12시간 (AI 병렬 처리) |
| 생성 파일 | 61개 파일, 15,306줄 |
| 콘텐츠 | 이론 5챕터 (2,337줄 MD) + 객관식 100문항 (JSON) |
| 빌드 상태 | ✅ tsc + lint + build 통과 |

### 구조

- 2과목 (데이터 모델링 + SQL 기본/활용)
- 5챕터, 50문항 모의고사, 90분 타이머
- localStorage 기반 진도 관리
- Next.js 14 SSG + Tailwind CSS + OPUS-X 퍼플 팔레트

### 주요 설계 결정

| 결정 | 근거 |
|------|------|
| Pages Router | SSG 패턴이 더 직관적 |
| JSON 파일 문제 관리 | Git 버전 관리, PR 기반 추가·수정 |
| localStorage | 회원가입 없이 즉시 사용 |
| SSG | 정적 데이터 → CDN 서빙 최적 |

### 교훈

- `getStaticPaths` + `getStaticProps` 패턴: SSG에서 동적 경로 사전 생성의 핵심
- localStorage SSR 가드: `typeof window !== 'undefined'` 빠뜨리면 hydration mismatch
- 챕터 단일 소스(`CHAPTERS` 배열): 여러 곳에서 ID를 하드코딩하면 일관성 깨짐
