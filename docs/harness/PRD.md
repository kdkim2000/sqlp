# PRD — SQLP 시험 준비 사이트

## 개요

SQLP(SQL 전문가) 자격증 시험을 준비하는 학습자를 위한 이론 학습 + 예상문제 풀이 + 실기 연습 웹 사이트.

- **목표 사용자**: SQLP 시험 준비생 (SQL 중급~고급 학습자, SQLD 취득 후)
- **핵심 가치**: 3과목 심화 이론 + 객관식 반복 풀이 + 실기 SQL 작성 연습

---

## 시험 구조

SQLP는 3과목 + 실기로 구성. 전체 60점 이상 + 과목별 40% 이상 합격.

| 과목 | 제목 | 객관식 | 실기 | 배점 |
|------|------|--------|------|------|
| 1과목 | 데이터 모델링의 이해 | 10문항 | — | 10점 |
| 2과목 | SQL 기본 및 활용 | 20문항 | — | 20점 |
| 3과목 | SQL 고급활용 및 튜닝 | 40문항 | — | 40점 |
| 실기 | SQL튜닝/성능트러블슈팅 | — | 2문항 | 30점 (15점×2) |
| **합계** | | **70** | **2** | **100점 / 180분** |

### 챕터 목록 (12챕터)

**1과목 (2챕터)**
- 1장: 데이터 모델링의 이해 (엔터티·속성·관계·식별자)
- 2장: 데이터 모델과 SQL (정규화·조인·NULL·본질/인조식별자)

**2과목 (3챕터)**
- 1장: SQL 기본 (SELECT·함수·WHERE·GROUP BY·JOIN·표준조인)
- 2장: SQL 활용 (서브쿼리·집합연산자·그룹함수·윈도우함수·Top N·계층형·PIVOT·정규표현식)
- 3장: 관리 구문 (DML·TCL·DDL·DCL)

**3과목 (7챕터, 신규)**
- 1장: SQL 수행 구조 (DB 아키텍처·SQL 처리 과정·I/O 메커니즘)
- 2장: SQL 분석 도구 (예상 실행계획·SQL 트레이스·응답시간 분석)
- 3장: 인덱스 튜닝 (기본원리·테이블 액세스 최소화·스캔 효율화·인덱스 설계)
- 4장: 조인 튜닝 (NL 조인·소트머지조인·해시조인·스칼라서브쿼리·고급조인)
- 5장: SQL 옵티마이저 (옵티마이징 원리·SQL 공유/재사용·쿼리 변환)
- 6장: 고급 SQL 튜닝 (소트튜닝·DML튜닝·DB Call 최소화·파티셔닝·배치·고급SQL)
- 7장: Lock과 트랜잭션 동시성 제어

### 실기 문제 유형

**가. SQL 튜닝 (3유형)**
- 유형1: 성능 저하 SQL + 실행계획 분석 → 개선 SQL 작성
- 유형2: 요구사항 + 최적 실행계획 → SQL 작성
- 유형3: 요구사항 + 데이터 모델 → 최적 SQL 작성

**나. 성능 트러블슈팅 (2유형)**
- 유형1: 성능 저하 애플리케이션 분석 → 개선안 작성
- 유형2: 다양한 성능 이슈 원인 분석 및 개선 방안 제시

## 핵심 기능

### 1. 이론 학습

- 3과목 12챕터 이론 콘텐츠 (텍스트 + 코드 예제 + 표)
- 챕터별 TOC 자동 생성 + 스크롤 스파이
- SQL 예제 코드 하이라이팅
- 관련 문제 미리보기 (챕터 우측)

### 2. 객관식 문제 풀이

**학습 풀 (~220문항 목표)**

| 과목 | 챕터 | 목표 문항 |
|------|------|---------|
| 1과목 | 1~2장 | 35 |
| 2과목 | 1~3장 | 65 |
| 3과목 | 1~7장 | 120 |

**풀이 모드**
- **단원별 풀이**: 특정 챕터 문제만 선택 (진도별 학습)
- **전체 모의고사**: 70문항 (1과목 10 + 2과목 20 + 3과목 40), 제한 시간 180분
- **오답 재풀이**: 틀린 문제만 모아서 재시도
- **북마크 풀이**: 북마크한 문제만 풀기

### 3. 실기 연습 [신규]

- 실기 문제 목록 (SQL튜닝·성능트러블슈팅 유형별)
- 지문 + SQL 작성 텍스트에어리어
- 모범 답안 토글 (제출 후 공개)
- 자기채점: 0점 / 7점(부분) / 15점(만점)

### 4. 학습 진도 관리 (localStorage)

- 문제별 정답/오답 기록
- 3과목·챕터별 정답률 통계
- 북마크 (오답 노트 대용)
- 모의고사 이력 (3과목 점수 분리)

### 5. 대시보드

- 3과목 진도율 차트
- 챕터 버블 경로 (12챕터)
- 취약 챕터 하이라이트
- 최근 모의고사 점수

## 페이지 구조

```
/                        → 대시보드 (3과목 진도율)
/theory                  → 이론 목차 (12챕터)
/theory/[chapterId]      → 챕터별 이론 본문 (SSG)
/quiz                    → 문제풀이 메뉴
/quiz/chapter/[id]       → 단원별 문제풀이
/quiz/exam               → 전체 모의고사 (70문항, 180분)
/quiz/result             → 모의고사 결과 (3과목 점수)
/quiz/wrong              → 오답 재풀이
/quiz/bookmarks          → 북마크 문제
/quiz/practical          → 실기 연습 목록 [신규]
/practical/[practiceId]  → 실기 상세 풀이 [신규]
```
